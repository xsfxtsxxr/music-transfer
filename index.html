关于新版加密变体

.mflac0 / .mgg1 / .mggl / .kgg / .kgma / .kwma 等新版格式的密钥由平台服务器或客户端账号数据库下发。纯离线工具拿不到这把钥匙，本站明确拒绝处理，也不会产出看似成功、实则损坏的文件。带本地 ekey 的 QMC 文件（含 QTag 尾部）依然可以正常解锁。

使用说明与边界

三分钟搞清楚这个工具在做什么

01

是「解密还原」，不是「转码」

加密文件内部本来就是完整的 MP3 / FLAC / M4A 音频流，只是被逐字节异或打乱了。音锁把它还原成原始字节，因此零音质损失；输出后缀由文件魔数自动判定，而不是强行改成 .mp3。若确实需要改变编码格式，请用 ffmpeg 等工具做二次转码。

02

文件不出本机

页面加载后不发起任何音频上传请求；解密在 Web Worker 中本地完成，服务器只提供静态 HTML / JS。可用断网环境验证。NCM 内嵌的歌名、歌手、专辑与封面会被解析并展示，封面可单独下载或随 ZIP 打包；本站不改写 ID3 / FLAC 标签。

03

仅用于你合法持有的音频

请仅将本工具用于自己在各平台合法下载、供个人跨设备播放与备份的音频文件，并遵守相应服务条款与所在地法律法规。本站不提供绕过付费、账号体系或获取未授权内容的能力，也不请求任何平台服务器密钥。

为什么有些文件显示「需要服务器密钥」？

新版加密把密钥放在服务端，或绑定客户端登录态与本地数据库。这类密钥无法通过文件本身推导，任何声称能纯网页离线解开的站点都值得怀疑。本站选择明确报错，而不是生成无法播放的坏文件。

解密后歌名、封面信息还在吗？

NCM 容器里单独存了一份元数据和封面图，本站会解析出来展示，并可单独下载封面 / 随 ZIP 一起打包。音频流本身若原本带有 ID3 或 FLAC 标签，也会原样保留；本站不会主动改写标签。

支持整个文件夹、超大 FLAC 或断点续传吗？

可一次选择 / 拖入多个文件（浏览器不支持直接拖入文件夹，请先全选文件）。解密过程按 1 MB 分块并让出执行，几十 MB 的无损文件也能稳定处理。任务是纯本地的，刷新页面即清空，不保存任何文件到服务器。

酷狗的大掩码表去哪里找？

它是开源社区从客户端提取的公开静态常量，通常名为 kgm.maskfile 或 kugou_key.xz（xz 需先在本机解压为 .bin / .gz）。本站不托管、不自动下载该表，由你自行提供并全程留在本机内存中。
